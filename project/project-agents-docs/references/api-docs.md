# RESTful API 文档规范

前后端接口文档放在 `docs/api/`，按领域或版本拆分，例如 `docs/api/{domain}-v1.md`。定义必须与代码、路由和测试一致，无法确认的字段标记“待补充”。

每个接口至少包含：方法与路径、版本、用途、鉴权与权限；请求头、路径/查询参数、请求体字段（类型、必填、约束、示例）；成功响应结构和示例；业务错误码与 HTTP 状态码及失败示例；幂等性、分页/排序、限流、超时、重试和兼容策略；关联数据模型、变更记录、前端联调注意事项。

优先使用 OpenAPI 3 作为机器可读契约；Markdown 作为人读入口并链接规范文件。接口变更同步需求 PLAN、API 文档和 CHANGELOG，必要时在 payload 保存脱敏样例。
